SoftwareApplication, Person, ViewAction, EntryPoint

PRE-MARKUP:

This example demonstrates structured data for a software application (a fictional sourceport). It showcases how to describe software details using SoftwareApplication, identify the developer using Person, specify the software version and publication date, provide screenshots and video demonstrations, identify the original project using isBasedOn, and define website and download entry points using ViewAction and EntryPoint. It also demonstrates linking a downloadable application to its website, software identity, operating system, and discussion page.

MICRODATA:

Example is JSON-LD only.

RDFA:

Example is JSON-LD only.

JSON:
HTML
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "SoftwareApplication",
  "name": "Sourceport name",
  "softwareVersion": "1.1.0",
  "author": {
    "@type": "Person",
    "name": "developer name"
  },
  "datePublished": "2001-01-01",
  "screenshot": "https://example.com/image.png",
  "video": "https://example.com/video.mp4",
  "operatingSystem": "Windows",
  "isBasedOn": "https://example.com/original-work",
  "potentialAction": {
    "@type": "ViewAction",
    "target": [
      "https://example.com.br",
      {
        "@type": "EntryPoint",
        "urlTemplate": "https://example.com.br",
        "contentType": "text/html"
      },
      {
        "@type": "EntryPoint",
        "urlTemplate": "https://example.com.br/download",
        "contentType": "application/octet-stream",
        "actionApplication": {
          "@type": "SoftwareApplication",
          "@id": "https://example.com.br/#software",
          "name": "Sourceport",
          "operatingSystem": "Windows",
          "discussionUrl": "https://example.com.br/discussions"
        }
      }
    ]
  }
}
</script>
